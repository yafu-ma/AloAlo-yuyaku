# AloAlo 予約フォーム

実家のサロンの公式LINEから開ける予約フォームです。2026年6月に個人で開発し、現在も実際の予約受付に使われています。

## 作った理由
サロンでは、公式LINEに届く予約に家族が手作業で返信し、お客様もメニューを見ながら予約内容を文章で打ち込んでいました。お客様が普段使っているLINEの中だけで予約が終わり、サロンには予約内容が決まった形で届くようにするために作りました。

## できること
- 名前とメニューを選ぶ（30種類近くから最大5つ）と、カウンセリング30分を含めた所要時間を自動で計算
- 希望の日付と開始時間を選んで確定すると、予約内容がLINEのトークでサロンに送られ、フォームが自動で閉じる
- 名前・日時の入力漏れや、過去の日付をチェック
- LINEの外で開いたときは送信せず、送る内容を画面に表示（確認用）

## 使い方の流れ
1. 公式LINEのリッチメニューの「予約」ボタンを押す
2. LINEの中で予約フォームが開く
3. 名前とメニューを選ぶ → 日付と開始時間を選ぶ → 「予約を確定する」
4. サロンはいつものトーク画面で予約を受け取り、返信して確定する

## 使った技術
- HTML / CSS / JavaScript（`index.html` 1ファイル）
- LINE LIFF（LINEの中でWebページを開く仕組み）
- GitHub Pages（公開）

## 工夫したこと
- 最初はGoogle Apps Scriptで予約の確定まで自動にする仕組みも試しましたが、うまく動かせませんでした。そこで、まずはサロンで早く使ってもらえることを優先し、サーバーを使わないシンプルな構成で完成させました
- 予約はサロンが返信して確定する運用なので、細かい制限はあえて入れず、個人のサロンが臨機応変に対応できる形にしました

## 今後の改善点
- 今は予約をデータベースで管理しておらず、届いた予約にサロンが返信して確定しています
- 最初にうまく動かせなかったGoogle Apps Scriptに改めて取り組み、予約をデータとして管理して、空き状況の確認から予約の確定・お客様への返信までを全自動で完了できるようにしたいと考えています
